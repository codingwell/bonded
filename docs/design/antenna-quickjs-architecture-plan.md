# 918 MHz Directional Antenna Architecture Plan

## Phase 0: Define scope (1–2 days)
- Target: **918 MHz directional antenna design workflow**
- Note: **918 MHz is the explicit design target** within the broader 902–928 MHz ISM band.
- v1 capabilities:
  - QuickJS-WASM parametric geometry
  - FEM-ready IR export
  - S11-first optimization loop
- v1 non-goals:
  - STEP/STL import
  - full CAD editor
  - distributed cloud solving

## Phase 1: Script runtime + schema contract (3–5 days)
- Implement QuickJS-WASM sandbox in browser.
- Define DSL entrypoints:
  - `defineParams(): ParamSchema`
  - `buildModel(params, api): ModelIR`
- Add strict runtime guards:
  - no network/filesystem
  - execution timeout
  - memory cap
- Output: validated `ParamSchema`, `ModelIR`.

## Phase 2: Arbitrary parameter system (4–6 days)
- Build generic schema types:
  - `number`, `int`, `bool`, `string`, `enum`, `vector`
- Add validation:
  - required/default/min/max/step/units
  - custom constraints callback support
- UI autogeneration from schema:
  - form controls + units
  - error surfacing mapped to parameter keys
- Persist/load parameter sets as JSON presets.

## Phase 3: Geometry API + IR compiler (1–2 weeks)
- Provide JS API primitives:
  - `box`, `cylinder`, `sheetRect`, `polygon().extrude()`, boolean ops
  - `material`, `assignMaterial`
  - `lumpedPort`, `airbox`, `pml`, mesh hints
- Compile script-created scene into canonical IR:
  - entities, tags, materials, ports, boundaries, mesh directives
- Add geometry sanity checks:
  - non-manifold detection
  - zero-thickness/degenerate entities
  - intersect/overlap checks where feasible

## Phase 4: Meshing bridge (1 week)
- IR → mesher input (Gmsh pipeline).
- Local refinement rules from script hints:
  - feed gaps, conductor edges, dielectric boundaries
- Mesh quality report and failure diagnostics in UI.

## Phase 5: FEM solver integration (2–4 weeks)
- Frequency-domain FEM interface (can be local/native backend initially).
- Inputs: mesh + materials + BC + ports.
- Outputs:
  - `Zin(f)`, `S11(f)`, resonant frequency
  - optional near-field slices
- Add solver job abstraction so browser can run:
  - local worker (small models) or remote solver API (larger models).

## Phase 6: 918 MHz directional templates (4–6 days)
- Ship starter scripts:
  - `918_patch_petg.js`
  - `918_yagi_directional.js`
  - `918_patch_parasitic_petg.js`
- Each template includes:
  - parameter schema
  - default sweep band (e.g., 850–980 MHz)
  - objective placeholders

## Phase 7: Sweep + optimization engine (1–2 weeks)
- Generic sweep runner powered by schema:
  - single param, grid, random
- Objective DSL:
  - maximize `boresight_realized_gain@918MHz [dBi]`
  - constrain `S11(918) < -10 dB`
  - optional band constraints (902–928 MHz)
- Save run history, best candidate, and param provenance.

## Phase 8: PETG calibration workflow (3–5 days)
- Add material calibration mode:
  - user inputs measured resonance shift
  - fit effective PETG `εr` / `tanδ`
- Store calibrated material profiles per printer/settings.

## Phase 9: QA + validation (ongoing; hard gate 1 week)
- Unit tests:
  - schema validation
  - script sandbox behavior
  - IR integrity
- Physics regression:
  - reference patch benchmark
  - enclosure detuning trend checks
- Determinism tests for script execution/IR output.

---

## Deliverables by milestone

- **M1:** Browser script runs and returns parameter schema.
- **M2:** Arbitrary parameters drive autogenerated UI and validation.
- **M3:** Script compiles to valid IR + mesh preview.
- **M4:** End-to-end S11 plot from scripted model.
- **M5:** One-click 918 MHz template sweep with best-result report.

---

## Suggested repo structure

- `packages/dsl-runtime` (QuickJS-WASM host, sandbox)
- `packages/dsl-api` (geometry/material/port API exposed to scripts)
- `packages/param-schema` (types + validation)
- `packages/model-ir` (IR types + serializers)
- `packages/mesh-bridge` (IR→Gmsh)
- `packages/solver-client` (FEM job interface)
- `apps/web` (UI: editor, params, plots, runs)
- `examples/` (top-level production starter templates shipped with the app for quick discovery and copy/use)
